# 01 — Offer & Packages

## One promise
"Wir bauen Software, die Ihre Prozesse von selbst laufen lässt."
Four delivery forms, one promise:
1. **Automatisierung** — repetitive workflows, integrations, data pipelines.
2. **KI-Agenten** — assistants/agents on the client's data and tools (email triage, quoting,
   document handling, internal Q&A).
3. **Dashboards** — live KPIs from ERP/CRM/Excel chaos; one screen of truth.
4. **Individualsoftware** — small custom applications where off-the-shelf fails.

## Productized packages (v1 prices per D-007; Partner A may adjust)
- **P1 Prozess-Audit** — fixed price, 1 week. Map 3–5 processes, quantify hours lost, deliver an
  automation roadmap with ROI estimate. **1.900 € Festpreis.**
- **P2 Automation Sprint** — 2–4 weeks. Implement the top roadmap item end-to-end incl. handover
  doc. **7.500–12.000 € nach Umfang** (quote per Angebot).
- **P3 Betrieb & Ausbau** — monthly retainer. Monitoring, fixes, iterative extensions.
  **1.200 €/Monat, Mindestlaufzeit 3 Monate.**
All prices netto zzgl. USt.

## Ideal client profile
Mittelstand, roughly 10–250 employees, in Partner A's network vertical (define after first
3 conversations). Symptoms: Excel as database, manual copy-paste between systems, "one person
knows how it works", reporting takes days.

## Qualification (Partner A checklist)
Budget authority present? Concrete process pain named? Data accessible (not locked in a hostile
IT landscape)? Timeline < 3 months? If <3 yes → not now, nurture.

## Out of scope v1
Security services, 24/7 SLAs, hardware/IoT, staffing, marketing websites for clients.
